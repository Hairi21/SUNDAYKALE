KASIR & PEMBUKUAN - VERSI PDF

Perubahan:
- Export CSV diganti menjadi Export PDF.
- PDF otomatis berisi ringkasan uang masuk, pengeluaran, laba, margin.
- PDF berisi tabel lengkap transaksi: tanggal, jenis, nomor, pelanggan/supplier, keterangan/bahan, metode/satuan, masuk, keluar.
- Tabel otomatis berlanjut ke halaman berikutnya.
- Format A4 landscape.
- PDF menggunakan jsPDF + AutoTable.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html.
3. Pada menu Laporan, pilih bulan.
4. Tekan Export PDF.
5. Jika pertama kali membuka sistem tanpa internet, library PDF perlu dimuat sekali dari CDN.


BARCODE: Kasir memiliki input kode, scanner kamera, serta kompatibilitas scanner USB/Bluetooth (scanner keyboard). Produk perlu memiliki field code/kode/barcode yang unik. Kamera umumnya membutuhkan HTTPS/localhost.
